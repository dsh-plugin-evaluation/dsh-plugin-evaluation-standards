# DSH プラグイン評価データセット

[English](README.md) | [中文](README.zh.md) | 日本語

> DSH プラグイン向けの、コミュニティで管理されるバージョン固定可能な評価データセットカタログです。

利用者はプラグインに合うデータセットを探し、テストケースと評価指標を確認して、固定バージョンを DSH プラグイン評価センターに読み込ませることができます。大規模なコミュニティデータセットは作者自身の GitHub リポジトリで管理し、このリポジトリにはカタログ情報だけを登録できます。

これは DeepSeek または DSH の公式プロジェクトではありません。掲載は品質、安全性、公式認定を意味しません。

## クイックスタート

1. [データセットカタログ](#データセットカタログ)でプラグイン種別とシナリオから探します。
2. 固定 Git tag または commit SHA を選びます。
3. 評価センターに profile、cases、metrics を読み込ませます。
4. 期待結果との一致と、実行時間などの観測値を確認します。

適切なデータセットがない場合は、[AI 支援作成ガイド](AI_ASSISTED_AUTHORING.md)で草案を作成するか、外部データセットをカタログへ登録できます。

### ナレッジ検索 基本評価

インストール済みのナレッジソースから明確な事実を検索するプラグイン向けの、小規模な入門データセットです。

- **ID:** `default-v1`
- **バージョン:** `1.0.0`
- **プラグイン種別:** `knowledge-query`
- **シナリオ:** 返金申請期限、標準配送 SLA、電子請求書の送信先
- **ケース数:** 3
- **Profile:** [`profiles/default-v1.json`](profiles/default-v1.json)
- **Cases:** [`cases/default-v1.json`](cases/default-v1.json)
- **提供元:** このリポジトリに同梱

#### テストケース

| ケース | 入力目的 | 期待結果 |
| --- | --- | --- |
| 返金申請期限の検索 | デフォルトの返金申請期限を検索 | `30 日` |
| 標準配送 SLA の検索 | 標準配送の約束時間を検索 | `3 営業日` |
| 電子請求書送信先の検索 | 電子請求書の送信先を検索 | `注文に紐づくメールアドレス` |

#### 評価指標

- [`answer-matches-expected`](metrics/answer-matches-expected.json): LLM Judge が最終出力と期待結果の一致を判定し、合否を決めます。
- [`duration`](metrics/duration.json): 実行時間を記録します。合否には影響しません。

## カタログの仕組み

```text
カタログ閲覧 → データセット選択 → tag / commit SHA 固定 → DSH 読み込み → 評価実行
```

- **同梱データセット**：profile と cases をこのリポジトリで管理します。
- **外部データセット**：作者自身の GitHub リポジトリで管理し、このカタログには概要、固定バージョン、profile パスのみを登録します。

外部データセットは `v1.0.0` のようなセマンティックバージョン tag、または 40 文字の commit SHA を指定する必要があります。`main` などの変動ブランチは受け付けません。

## データセット形式

データセットは profile と cases ファイルで構成されます。

```text
profiles/<id>.json  指標と casesPath
cases/<id>.json     プラグイン種別とテストケース
```

各テストケースには次の項目があります。

```json
{
  "id": "case-id",
  "title": "ケース名",
  "prompt": "プラグインへ送る入力",
  "expected": "期待結果"
}
```

評価センターは `casesPath` を読み取り、各 `prompt` をプラグインへ送り、profile の指標で出力と `expected` を評価します。

## データセットのコントリビュート

- 手順は [`CONTRIBUTING.md`](CONTRIBUTING.md) を参照してください。
- 外部掲載要件は [`DATASET_LISTING.md`](DATASET_LISTING.md) を参照してください。
- 提出前に実行します。

```bash
npm run validate
npm test
```

カタログは同梱データセットの説明、ケース数、プラグイン種別、指標が実ファイルと一致することを確認します。外部エントリについては、必須情報と固定された GitHub バージョン参照を検証します。
