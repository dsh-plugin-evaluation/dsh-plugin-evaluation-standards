# DSH プラグイン評価セット

[English](README.md) | [中文](README.zh.md) | 日本語

> DSH プラグインを評価するために、そのまま使えるテストセットを集めています。

各評価セットには、テストする質問、期待する回答、評価指標が含まれています。自分のプラグインに近い評価セットを選び、実行して、さまざまな場面での動作を確認できます。

## まずはここから

1. [評価セット](#評価セット)から、プラグイン種別と利用場面に近いものを探します。
2. 該当する profile と cases ファイルを開きます。
3. 含まれているテスト質問をプラグインに実行します。
4. 回答が期待どおりか、実行時間なども確認します。

合う評価セットがまだない場合は、[AI 支援作成ガイド](AI_ASSISTED_AUTHORING.md)で草案を作成し、ここに追加できます。

## 評価セット

| 評価セット | 対象プラグイン | 対象シナリオ | ケース数 | 使用する指標 |
| --- | --- | --- | ---: | --- |
| [ナレッジ検索 基本評価](#ナレッジ検索-基本評価) | `knowledge-query` | 返金、配送、請求書 | 3 | `answer-matches-expected`、`duration` |

### ナレッジ検索 基本評価

インストール済みのナレッジソースから明確な事実を検索するプラグイン向けの、小さな入門評価セットです。

- **ID:** `default-v1`
- **バージョン:** `1.0.0`
- **対象プラグイン:** `knowledge-query`
- **対象内容:** 返金申請期限、標準配送の所要日数、電子請求書の送信先
- **ケース数:** 3
- **評価設定:** [`profiles/default-v1.json`](profiles/default-v1.json)
- **テストケース:** [`cases/default-v1.json`](cases/default-v1.json)

#### 含まれるテストケース

| ケース | 確認する内容 | 期待する回答 |
| --- | --- | --- |
| 返金申請期限の検索 | デフォルトの返金申請期限はいつまでか | `30 日` |
| 標準配送 SLA の検索 | 標準配送は何営業日で届くか | `3 営業日` |
| 電子請求書送信先の検索 | 電子請求書はどこに送られるか | `注文に紐づくメールアドレス` |

#### 使用する指標

- [`answer-matches-expected`](metrics/answer-matches-expected.json)：プラグインの最終回答が期待する回答と合っているかを判定します。この結果でケースの合否が決まります。
- [`duration`](metrics/duration.json)：ケースの実行時間を記録します。合否には影響しません。

## ファイルの構成

評価セットには 2 つのファイルがあります。

```text
profiles/<id>.json  使用する指標とテストケースの場所
cases/<id>.json     プラグイン種別と具体的なテストケース
```

テストケースはシンプルです。

```json
{
  "id": "case-id",
  "title": "ケース名",
  "prompt": "プラグインに送る質問",
  "expected": "期待する回答"
}
```

## 現在利用できる指標

| 指標種別 | 現在使えるか | 合否に影響するか |
| --- | --- | --- |
| `llm_judge` | 使える | する |
| `observation` | 使える | しない |
| `tool_trace` | まだ使えない | しない |
| `threshold` | まだ使えない | しない |

## 評価セットを追加したい場合

小さな評価セットはこのリポジトリに直接追加できます。データが多い場合は、自分のリポジトリで管理し、このカタログに追加することもできます。

提出前に次を確認してください。

- [コントリビューションガイド](CONTRIBUTING.md)
- [外部評価セットの掲載ガイド](DATASET_LISTING.md)

次のコマンドも実行します。

```bash
npm run validate
npm test
```
